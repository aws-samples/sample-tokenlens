# Support

TokenLens is beta software provided under the MIT No Attribution (MIT-0)
License. It is not an
AWS service and does not include an AWS Support commitment, service-level
agreement, or production warranty.

## Community support

Use GitHub issues for reproducible bugs, documentation corrections, and focused
feature requests. Include:

- TokenLens version and installation method;
- operating system and Python version;
- minimal reproduction steps;
- expected and actual behavior;
- sanitized logs or error messages;
- relevant configuration with secrets removed.

Responses and fixes are provided on a best-effort basis. General AWS service
questions should use the applicable AWS documentation or support channel.

## Security issues

Do not file public issues for vulnerabilities. Follow [SECURITY.md](SECURITY.md)
for private reporting instructions.
